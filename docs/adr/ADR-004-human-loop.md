# ADR-004 – Human-in-the-Loop Prinzip

## Status
Accepted

## Kontext
Die personelle Planung im Pflegebereich erfordert Verantwortung, Erfahrung und situatives Urteil.

## Entscheidung
CareFlow wird als unterstützendes System konzipiert.

Die finale Entscheidung bleibt immer bei der Führungsperson.

Das System:
- gibt Hinweise
- zeigt Risiken
- liefert Begründungen

Es entscheidet nicht autonom.

## Begründung
- Verantwortung bleibt beim Menschen
- höhere Akzeptanz im Alltag
- Vermeidung von Fehlentscheidungen durch Automatisierung

## Konsequenzen
- System ist Assistenz, kein Autopilot
- Nutzer bleibt aktiv eingebunden
- Fokus auf Entscheidungsunterstützung

## Alternativen
- vollautomatisches Planungssystem (verworfen wegen Kontrollverlust und geringer Akzeptanz)
