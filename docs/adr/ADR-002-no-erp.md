# ADR-002 – Keine ERP-Integration im MVP

## Status
Accepted

## Kontext
Viele bestehende Systeme im Pflegebereich sind ERP- oder HR-lastig. CareFlow soll bewusst als unabhängiges Führungsinstrument positioniert werden.

## Entscheidung
Im MVP wird keine Integration mit ERP-, HR- oder Finanzsystemen umgesetzt.

Alle Daten werden:
- manuell erfasst
- oder über einfache Importmechanismen bereitgestellt

## Begründung
- geringere technische Komplexität
- schnellere Entwicklung
- klare Abgrenzung zu bestehenden Systemen
- Fokus auf Führungsfunktion statt Administration

## Konsequenzen
- zusätzlicher Aufwand für Dateneingabe
- eingeschränkte Automatisierung im MVP
- spätere Integrationsoption bleibt offen

## Alternativen
- direkte ERP-Integration (verworfen wegen hoher Komplexität und Abhängigkeiten)
