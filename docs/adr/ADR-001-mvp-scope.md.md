# ADR-001 – MVP Scope Definition

## Status
Accepted

## Kontext
CareFlow soll als Führungsinstrument für die personelle Steuerung in Pflegeheimen entwickelt werden. Um eine schnelle Umsetzbarkeit und klare Nutzbarkeit zu gewährleisten, muss der Funktionsumfang für Version 0.1 bewusst begrenzt werden.

## Entscheidung
Das MVP V0.1 umfasst ausschließlich:

- Stammdaten von Mitarbeitenden (Pensum, Qualifikation, Verfügbarkeit, Absenzen)
- Definition von Schichten und Mindestanforderungen
- Monatsplanung für den Folgemonat
- Regelbasierte Prüfung der Planung
- Erkennung von Risiken (Unterbesetzung, Skill-Mix, kritische Schichten)
- Ausgabe von Warnungen und einfachen Begründungen

Nicht Teil des MVP:
- ERP-Integration
- automatische KI-Optimierung
- Benchmarking
- komplexe Forecast-Modelle
- organisationsübergreifende Vergleiche

## Begründung
Ein klar abgegrenztes MVP ermöglicht:
- schnelle Entwicklung
- frühe Validierung im Praxiskontext
- Reduktion technischer Komplexität

## Konsequenzen
- schneller Start möglich
- begrenzter Funktionsumfang
- klare Grundlage für spätere Erweiterungen

## Alternativen
- breiter Funktionsumfang im MVP (verworfen wegen Komplexität und Verzögerung)
